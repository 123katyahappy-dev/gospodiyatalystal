ARTMENTOR — КАК УСТАНОВИТЬ

1. Скопируй app.py, ai_functions.py, data_functions.py и requirements.txt в корневую папку своего проекта (туда, где сейчас лежит старый app.py).
2. Если Windows спросит о замене файлов, замени эти четыре файла. Старые версии предварительно можно сохранить в отдельную папку backup.
3. В PyCharm открой Terminal в папке проекта и выполни:
   pip install -r requirements.txt
4. Создай в корне проекта папку .streamlit, а внутри файл secrets.toml.
   В secrets.toml добавь строку:
   GEMINI_API_KEY = "ТВОЙ_КЛЮЧ"
   Не отправляй этот файл в чат и не загружай его на GitHub.
5. Запусти приложение командой:
   streamlit run app.py

Важно: настоящий AI-анализ заработает только после добавления действительного Gemini API key. Ключ и доступ к API должен настроить взрослый, если для этого требуется взрослый аккаунт или согласие. Бесплатный лимит и доступность модели могут меняться. Не загружай чужие или приватные рисунки без разрешения.

История сохраняется локально в папке data. При публикации на Streamlit Cloud локальные файлы могут не сохраняться постоянно между перезапусками.
